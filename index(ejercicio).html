Esta pagina va a resumir los principales conceptos y etiquetas HTML

Conceptos principales HTML

HTML

El lenguaje de marcado de hipertexto se utiliza para estructurar sitios web

Elemento HTML

un elemento HTML esla unidad basica de estructura

  1. Etiqueta de apertura
  2. Pares, atriburos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

Es una etiqueta que se utiliza para comunicarse con el navegador a traves de los metadatos, ademas enlaza archivos externos de estilos o scripts

Etiqueta <Body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

<header> Es una etiqueta utilizada pra el contenido introductorio de una pagina web, puede contener el logo, el menu de navegacion princpal, el nombre de la empresa, etc.
<nav> Etiqueta utilizada para el menu de navegacion principal, suele contener enlaces a otras paginas relacionadas, o navegar por la pagina principal
<main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web
<section> es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una oagina web en secciones, y agrupar contenido relacionado
<article> es una etiqueta que se utiliza para agrupar contenido autonomo que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> es una etiqueta que normalmente se encuentra hasta el final de una pagina y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra informacion complementaria
aside Esta etiqueta representa una seccion de la pagina web cuyo contenido no esta directamente relacionado con el contenido principal del documento como: barras laterales, publicidad, enlaces a otros articulos relacionados, etc

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces a otras paginas

  • Externos
  • Interos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/203948920"
Envia un whatsapp a un numero especificado
href="mailto:example@gmail.com"
Envia un correo a un mail especifico
